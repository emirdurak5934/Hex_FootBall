# EDYN Games açılış videosu

Kendi videonu bu klasöre aşağıdaki adla koy:

`edyn_games_intro.mp4`

Önerilen dışa aktarma ayarları:

- Dikey çözünürlük: 1080x1920 (9:16)
- Video codec: H.264
- Pixel format: yuv420p
- Süre: yaklaşık 3 saniye
- Web/streaming optimizasyonu: fast start
- Ses zorunlu değil; açılış videosu iPhone otomatik oynatma kuralları için sessiz oynatılır.

Dosya adı ve konumu aynı kaldığı sürece HTML, CSS veya JavaScript dosyalarını değiştirmen gerekmez.
